|---|---|
| `prototype.jpg` | The complete assembled kiosk |

In the root `README.md`, replace each “Photo to be added” line with its Markdown image line. For example:

```markdown
![Complete biometric access-control prototype](images/prototype.jpg)
```

The relative path is measured from the root README. Use the exact filename and extension, including capitalization. A `.png` image needs a `.png` path; do not rename its extension just to match the example.

Do not upload passwords, device keys, readable test PINs, private preview URLs, or identifiable biometric images without the participant's permission. Crop or redact dashboard screenshots before sharing them.

Photos are not included in this package; the placeholders stay visible until you add them.
